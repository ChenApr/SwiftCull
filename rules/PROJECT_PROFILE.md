# SwiftCull 项目档案

## 目标

- 项目目标：修复 JPG+RAW 照片筛选显示，并在导出时提供将 JPG 与 RAW 分别放入两个文件夹的选项。
- 当前任务：在本地完成实现与测试；测试通过后，在用户授权范围内创建分支并推送到原 GitHub 项目以便提交 PR。

## 完成标准

- JPG+RAW 配对照片可按 JPG、RAW 或 JPG+RAW 选择并正确显示。
- 导出选项可将 JPG 和 RAW 分别导出到两个文件夹，且不破坏现有导出行为。
- 本地构建/测试通过，并保留可复核的测试命令与结果。
- 推送前确认工作树、分支和远端目标；不得把未测试的改动推送出去。

## 范围与权限

- 路径白名单：本仓库目录 `/Users/interesting/code/SwiftCull` 及其 Git 元数据。
- 原始照片和真实用户数据：仅在用户明确提供并授权时使用；默认不读取、不复制、不上传。
- 网络/GitHub 操作：用户已明确要求测试通过后推送 PR；具体账号、分支命名和 PR 内容仍按实际 Git 状态核验。
- 资源预算：本地可用开发工具与现有项目依赖；额外服务、付费资源和远程机器均为“待确认”。

## 阶段条件

- 探索：先阅读规则、代码、调用方、测试和 Git 状态。
- 候选选择：采用最小改动，并明确影响的服务、模型、视图、配置和测试。
- 正式评估：仅在本地测试通过后准备远程推送；测试失败时保留记录，不推送。
